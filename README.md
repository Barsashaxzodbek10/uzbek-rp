# UZBEK RP

Pydroid3/Pygame o‘rniga telefon brauzerida ishlaydigan Flask + HTML5 Canvas versiyasi.

## GitHub
1. GitHub'da yangi repository oching: `uzbek-rp`
2. Shu papkadagi fayllarni repository'ga yuklang.

## Render
1. Render.com'ga kiring.
2. New -> Web Service.
3. GitHub repository'ni tanlang.
4. Build Command:
   `pip install -r requirements.txt`
5. Start Command:
   `gunicorn app:app`
6. Deploy.

O‘yin telefon brauzerida ochiladi.
